05 / About

Catalog evidence,
spatial attention.

ShelfSignals is a static research interface for the Allan Sekula Library. It uses collection metadata from the Clark Art Institute catalog, verified cover references where available, and clearly labeled provider-edition evidence when an identifier match can enrich a synthetic book form.
